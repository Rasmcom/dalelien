# دليل الأنشطة والبرامج

موقع مستقل RTL، بدون تسجيل دخول، لعرض محتوى النشاط الطلابي حسب:
- الأولية
- العليا
- المتوسطة
- الثانوية

المجالات المعتمدة:
- المواطنة والحياة
- العلوم والتقنية
- الرياضة والصحة
- الثقافة والفنون
- النشاط الكشفي

## المزامنة
`npm run sync` يشغل متصفح Chromium ويقرأ صفحة عين، ويراقب JSON وروابط PDF في الشبكة/DOM، ثم يكتب الناتج إلى `data/catalog.json` و`data/catalog.js`.

Workflow داخل `.github/workflows/sync-ien.yml` يشغل المزامنة يوميًا. إذا لم يجد أي PDF يرجع بكود فشل حتى لا يتم استبدال فهرس صالح ببيانات فارغة.
